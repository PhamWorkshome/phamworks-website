# Estimate form setup (required before publishing)

The estimate page uses FormSubmit.co AJAX to deliver requests to info@phamworks.ca. This is a third-party service, not GitHub Pages functionality.

1. Publish the site to GitHub Pages.
2. Submit a TEST request through estimate.html using your own details.
3. Check info@phamworks.ca for the FormSubmit activation/confirmation email, and activate the form following its instructions. Check spam if needed.
4. Submit a second TEST request. Verify that it arrives in the mailbox AND the thank-you screen appears.
5. Do not advertise the form as working until delivery is verified.

FormSubmit free-tier availability, privacy, spam controls and limits are subject to the provider's terms. If you prefer a different form provider, the endpoint and integration can be changed.

Note: The uploaded site does not include the previously discussed wardrobe project photos or approved home-audio comparison images, so these have NOT been fabricated. Those sections can be updated once the correct image assets are supplied.
